# BatchVaria: variance-based evaluation of batch correction with provenance tracking

Code to reproduce analysis within BatchVaria application
note (https://doi.org/10.64898/2026.05.07.721996).  Every number in the text and Figure 1 can be recreated here. It downloads TCGA breast
cancer RNA-seq data, applies four batch corrections, and profiles the
variance of every resulting assay with BatchVaria.

The package, with its documentation, is at
[cmpmolonc/BatchVaria](https://github.com/cmpmolonc/BatchVaria).

## Citation

If you use this code, please cite the manuscript:

A machine-readable version is in `CITATION.cff`.

## Design

| | |
|---|---|
| Data | TCGA-BRCA, STAR gene counts, primary tumours, one RNA aliquot per patient |
| Batch variable | `plate_id`: the plate each RNA aliquot was sequenced on, read from its barcode |
| Biological variable | `paper_BRCA_Subtype_PAM50` (PAM50 calls from Berger *et al.*, 2018) |
| Corrections | ComBat and `limma::removeBatchEffect`, each naive (plate only) and subtype-protected |
| Variance profiling | `anova` engine: Type II sums of squares, pooled summarisation |

## Running the analysis

From the repository root:

```sh
Rscript run_all.R
```

To run a single step interactively, once the steps before it have run:

```r
PROJECT_ROOT <- getwd()
source("R/00_setup.R")
source("R/07_results_tables.R")
```

Step 01 skips the download if `data/raw/` exists; every other step
recomputes each time it runs.

### Configuration

All analysis choices are in `CONFIG` and `CORRECTIONS` in `R/00_setup.R`.

The GDC download (about 5 GB) goes to `GDCdata/` in the repository by
default. To reuse an existing TCGAbiolinks download, set `GDC_DIR`:

```sh
GDC_DIR=/path/to/GDCdata Rscript run_all.R
```

### Requirements

- R 4.6, Bioconductor 3.23
- BatchVaria 0.99.2
- `TCGAbiolinks`, `edgeR`, `limma`, `sva`, `matrixStats`, `ggplot2`,
  `patchwork`

A full run from an existing download can take over 30 minutes, with peak
memory of about 4 GB. `results/sessionInfo.txt` records the versions used.

## Pipeline

| Step | What it does | Output |
|---|---|---|
| `00_setup.R` | Paths, configuration and helper functions. | — |
| `01_download_tcga.R` | Downloads expression and biospecimen data from the GDC. | `data/raw/` |
| `02_sample_metadata.R` | Assigns plates, keeps one aliquot per patient, selects samples, records the sample flow. | `results/02_*.csv` |
| `03_preprocess.R` | Expression filtering, TMM normalisation, log2 CPM. | `data/processed/` |
| `04_build_object.R` | Checks the input object and design. | `data/processed/` |
| `05_corrections.R` | Runs the four corrections. | `data/processed/` |
| `06_profile_variance.R` | Profiles the variance of every assay. | `data/processed/` |
| `07_results_tables.R` | Fractions, totals, absolute contributions, fraction changes, basis retention. | `results/07_*.csv` |
| `08_figures.R` | Figure 1. | `figures/` |
| `09_weighting_comparison.R` | Feature-averaged vs pooled summaries; plate term against its noise-only level. | `results/09_*.csv` |
| `10_manuscript_numbers.R` | Collects the numbers quoted in the manuscript. | `results/10_manuscript_numbers.md` |

## Results

`results/10_manuscript_numbers.md` contains every number quoted in the
manuscript, each with the table it was read from. It is generated by step 10;
do not edit it by hand.

## Data availability

No TCGA data is included in this repository. `R/01_download_tcga.R`
downloads it from the Genomic Data Commons; its use is governed by the TCGA
data use terms. `data/`, `results/` and `figures/` are not tracked in git and
are produced by `run_all.R`.
